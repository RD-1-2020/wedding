# Отчёт о реализации 06

Замена выдуманного знака (два кольца) на обработанную копию настоящего логотипа из корня репозитория. Правки Review из прогона 05 (кино, карточка регистрации, пункт «Подтверждение») не откатывались.

Раздаваемый ассет `src/assets/logo.svg` получен из исходника `logo.svg` в корне репозитория (path-traced, 2048×2048). Исходный файл в корне не удалялся и не изменялся.

## Обработка логотипа

- Удалён первый path — непрозрачная заливка холста `#F8F3EE` (`M0 0 … 2048 … Z`).
- Фон знака прозрачный: монограмма сидит на шапке и подвале без кремового квадрата.
- `viewBox` сжат до живого рисунка (`93 638 1726 1381`, пропорция ≈ 5:4 по ширине), без пустого квадрата 2048.
- В шапке (`h-16`) знак 48×60 (`h-12 w-auto`), в подвале 56×70 (`h-14 w-auto`) — высота в диапазоне 40–56 px, без растягивания квадрата в 120×40.
- Доступное имя по-прежнему **«Вероника и Дмитрий»** (`alt` и `aria-label` ссылки `#home`).

## Реализованные истории

- US-01 — неон-герой; липкая шапка с настоящим `logo.svg` (alt / aria-label «Вероника и Дмитрий»), якоря История / Программа / Детали / **Подтверждение**, календарь; видимой подписи RSVP нет
- US-02 — таймер дни / часы / минуты / секунды; старт 15:30 / 14:30 по `full`
- US-03 — «Наша история»: Первое свидание, Путешествия, **Первый поход в кино 2025**, Предложение
- US-04 — короткая программа без регистрации; в **Локациях** только **Банкет**
- US-05 — при `?full=true` регистрация 14:30 в программе и карточка **Регистрация** в локациях
- US-06 — `calendar_month` → Google Календарь (26.12.2026, конец 22:30)
- US-07 — «Для гостей»: подарки, дресс-код, этаж, Марина
- US-08 — `#rsvp`, заголовок «Подтверждение присутствия», поля и срок 15 ноября
- US-09 — POST JSON на Cloud Run (`token` из query, поля с формы)
- US-10 — локации зависят от `full`; банкет всегда
- US-11 — якоря, порядок блоков, один обработанный `src/assets/logo.svg` в шапке и подвале
