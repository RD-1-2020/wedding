# Отчёт о реализации 05

Правки по Review-дельте из `docs/requirements.md`: история без «Знакомства», локация «Регистрация» только в полном режиме, навигация «Подтверждение», SVG-логотип вместо текста V&D. Тема Material 3 / Ethereal Union, таймер, Cloud Run RSVP и виджеты карт сохранены.

## Реализованные истории

- US-01 — неон-герой; липкая шапка с `logo.svg` (alt / aria-label «Вероника и Дмитрий»), якоря История / Программа / Детали / **Подтверждение**, календарь; видимой подписи RSVP нет
- US-02 — таймер дни / часы / минуты / секунды; старт 15:30 / 14:30 по `full`
- US-03 — «Наша история»: Первое свидание, Путешествия, **Первый поход в кино 2025**, Предложение; карточки «Знакомство» и слота `story-meeting` нет
- US-04 — короткая программа без регистрации; в **Локациях** только **Банкет** (Отель Slumo, Новая Заря, 53А); короткий виджет
- US-05 — при `?full=true` регистрация 14:30 в программе и карточка **Регистрация** в локациях; полный виджет
- US-06 — `calendar_month` → Google Календарь (26.12.2026, конец 22:30)
- US-07 — «Для гостей»: подарки, дресс-код, этаж, Марина
- US-08 — `#rsvp`, заголовок «Подтверждение присутствия», поля и срок 15 ноября
- US-09 — POST JSON на Cloud Run (`token` из query, поля с формы)
- US-10 — локации зависят от `full`; банкет всегда
- US-11 — якоря, порядок блоков, один `src/assets/logo.svg` в шапке и подвале

## Отложено

- URL Cloud Run в `RSVP_FUNCTION_URL` — плейсхолдер до деплоя функции
- Живые кадры вместо заглушки `story-cinema*`
- Неиспользуемые `story-meeting*` остаются в каталоге, в UI не показываются
