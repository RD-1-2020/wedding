## Контекст

Сайт-приглашение на свадьбу **Вероники и Дмитрия** (26.12.2026), бренд **Ethereal Union**. Одна страница по макету Stitch: шапка, неон-герой с таймером, приветствие, четыре карточки истории, золотой таймлайн программы, блок «Для гостей», RSVP, локации и подвал.

Макет: `docs/stitch_modern_material_redesign/`. Вид: `docs/DESIGN.md` (Angular Material 3). Старые паттерны (shadcn, волна weddingpost, лонгрид Yami `#time-line`, dusty-rose `#C4A4A5`) не действуют.

Режим `full=true`: в программе есть торжественная регистрация 14:30 и полный виджет Яндекс.Карт; иначе регистрация в расписании скрыта, виджет короткий. Обе карточки локаций всегда на месте.

RSVP уходит в Google Cloud Run и дальше в Telegram. Других бэкендов нет.

Исходные тексты гостя — `docs/user-requirements.md` (не изменять). Виджеты: `docs/widget-full.html`, `docs/widget-short.html`.

## Нефункциональные требования

### NFR-01 Русский интерфейс
**Приоритет:** Must  
Весь гостевой UI на русском. `index.html` `lang="ru"`. Строки в шаблонах, не латиница CLI.

### NFR-02 Палитра Stitch / M3
**Приоритет:** Must  
Токены и золото-металл — `docs/DESIGN.md`. Обязательны powder-pink `#F4C2C2`, real-gold `#D4AF37`, charcoal `#1B1C1B`, surface-warm `#FBF9F7`, neon-glow `#FFF0F5`. Горчица `#C6A15B` запрещена. Не использовать dusty-rose `#C4A4A5` и powder `#F4E8E1` как систему.

### NFR-03 Стек
**Приоритет:** Must  
Angular **22**, standalone, TypeScript. **Angular Material (Material 3)**. Playfair Display, Inter, Material Symbols Outlined. **Не** shadcn/ui, **не** Spartan, **не** Bootstrap, **не** CLI-заглушка. Сигналы, `inject()`, `input()` / `output()`, `@if` `@for` `@switch`, отдельные шаблоны, без `any`.

### NFR-04 Адаптив
**Приоритет:** Must  
Телефон и desktop **1920×1080**, без горизонтального скролла. На узкой ширине nav шапки не ломает бар. Карта вписывается в контейнер. Подробности — `docs/DESIGN.md`, «Адаптив».

### NFR-05 Фото
**Приоритет:** Must  
12 слотов и размеры — таблица в `docs/DESIGN.md`, «Ассеты фото». Каталог `src/assets/photos/`.

### NFR-06 Заглушки
**Приоритет:** Must  
Приёмка на заглушках тех же имён. Живое фото — то же имя, без смены вёрстки.

### NFR-07 Доступность
**Приоритет:** Must  
Заголовки; подписи полей (Имя, Фамилия); `alt` у героя и четырёх квадратов; фокус на ссылках, полях, чекбоксах, кнопках; имя у iframe карты; иконка календаря с текстом или `aria-label`. Контраст — DESIGN.md.

### NFR-08 Cloud Run RSVP
**Приоритет:** Must  
Одна HTTP-функция: JSON → Telegram. URL на фронте из конфигурации. Секреты только у функции.

### NFR-09 Запуск
**Приоритет:** Must  
`npm start` → `http://localhost:4200/`. Режим и предзаполнение — query.
