# Отчёт о реализации 08

Дельта к уже собранному приглашению: якорь шапки **Локация**, `id="locations"`, строка **зал Модерн** на карточке регистрации, карточки **Ведущая Марина** и **Чат для гостей** в сетке `#details`.

## Реализованные истории

- US-01 — липкая шапка: История / Программа / Детали / Подтверждение / **Локация**; видимой подписи RSVP нет
- US-05 — при `?full=true` карточка **Регистрация**: **Центральный ЗАГС**, отдельная строка **зал Модерн**, ссылка 2GIS **Красный проспект, 68**
- US-07 — `#details`: точный текст ведущей про творческий подарок, номер или сюрприз; телефон / Telegram / VK; карточка **Чат для гостей** без URL; ведущая не `col-span-2`; на desktop ведущая и чат рядом
- US-10 — без `full` нет **Регистрации**; с `full=true` регистрация с **зал Модерн**; банкет без изменений
- US-11 — desktop и mobile: `#story`, `#program`, `#details`, `#rsvp`, `#locations`; подпись якоря локаций — **Локация**
- US-12 — `#details article` по-прежнему с `appMotionReveal` (подарки, дресс-код, гардероб, ведущая, чат)
